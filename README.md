# work-page

Professional web profile for Promit Moitra — researcher in computational cognitive
neuroscience and complex systems, currently building canine EEG and olfaction systems
at Dognosis.

The site is a single self-contained `index.html` (no build step, no dependencies).

## Publish with GitHub Pages

1. Push this branch and open the repository **Settings → Pages**.
2. Under **Build and deployment**, set **Source** to *Deploy from a branch*.
3. Choose the branch and the `/ (root)` folder, then **Save**.
4. The profile will be served at `https://promitmoitra.github.io/work-page/`.

## Local preview

Open `index.html` directly in a browser, or run:

```sh
python3 -m http.server
```

then visit http://localhost:8000.
